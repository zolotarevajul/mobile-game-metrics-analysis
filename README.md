Проект: Анализ удержания пользователей мобильной игры.

Описание проекта: в рамках подготовки проекта была выведена функция на python для расчета Retention и визуализации показателя Retention Rate (удержания) игроков в мобильной игре по дням с момента регистрации пользователей. Анализ удержания важен для оценки наличия интереса к приложению, поиска "слабых мест".

Стек технологий: Python 3 (платформа Jupiter Notebook), библиотеки Pandas (предобработка и анализ данных), Seaborn, Matplotlib (визуализация, построение тепловой карты)

Входные данные: 
1. red_data - данные о регистрации пользователей (uid - уникальный идентификатор пользователя, reg_ts - unix timestamp времени регистрации) 
2. auth_data - данные об авторизации пользователей (uid - уникальный идентификатор пользователя, auth_ts - unix timestamp времени последнего входа в игру)

Выводы:

1) Для оптимизации работы данные были отфильтрованы с 2020 года, т.к. в памяти содержится информация за 20 лет, что влияет на работу кода (ядро "умирает")
   
2) Для анализа был выбран самый свежий период - первые 3 недели сентября 2020 г, т.к. более ранние данные менее актуальны. Для анализа взяты 3 недели, чтобы у каждой когорты на карте были точно 7 дней.
   
3) Анализ тепловой карты: В нулевой день retention равен 100% (день регистрации пользователей). Начиная с 1 дня выявляется большой отток на старте (в среднем в первый день возврат около 2,1 игроков), при этом с 4 по 7 день наблюдается рост метрики (в диапазоне от 3,4 до 8,6 игроков)
